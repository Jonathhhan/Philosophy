# Kapitel 2: Unterbrechen

## 1. Wenn Fortsetzung fraglich wird

Anschließen vollzieht sich unter Bedingungen, die nicht in jedem Augenblick ausdrücklich werden müssen. Wer spricht, vergegenwärtigt sich nicht bei jedem Satz die Grammatik der eigenen Sprache. Wer ein vertrautes Werkzeug gebraucht, untersucht nicht fortwährend dessen Konstruktion. Solange ein Vollzug gelingt, kann sich die Aufmerksamkeit auf das richten, was getan werden soll. Die Bedingungen des Tuns wirken mit, ohne selbst zum Gegenstand der Aufmerksamkeit zu werden.

Diese Unauffälligkeit kann dort enden, wo eine erwartete Fortsetzung nicht zustande kommt. Eine Antwort bleibt aus. Ein Werkzeug erfüllt seine Funktion nicht. Eine eingeübte Bewegung lässt sich nicht ausführen. Eine Folge von Bildern kann nicht in der vorgesehenen Weise weitergeführt werden. Der Zusammenhang muss dadurch nicht enden. Aber seine Fortsetzbarkeit verliert ihre Selbstverständlichkeit.

Unterbrechen bezeichnet zunächst diese Veränderung im Verhältnis eines Verlaufs zu seinen möglichen Fortsetzungen. Etwas kann nicht einfach so weitergehen wie bisher. Eine Fortsetzung fällt aus, wird ausgesetzt oder erweist sich als nicht verfügbar. Unterbrechen entzieht ihr die Selbstverständlichkeit und macht bemerkbar, dass das Weitergehen von Bedingungen abhing.

Damit ist noch nicht bestimmt, welche Bedingungen wirksam waren. Das Ausbleiben einer Antwort kann an einer unklaren Äußerung, an verschiedenen Erwartungen, an einem Konflikt oder an Umständen liegen, die mit dem Gesagten nur mittelbar zusammenhängen. Die Unterbrechung liefert keine fertige Erklärung. Sie verändert zunächst, worauf sich die Aufmerksamkeit richten kann.

## 2. Erwartung und Fortsetzbarkeit

Etwas kann nur dort als Unterbrechung erscheinen, wo eine Fortsetzung erwartet, vorbereitet oder zumindest für möglich gehalten wurde. Diese Erwartung muss nicht bewusst formuliert sein. Wer eine Treppe hinabgeht, entwirft keine Theorie ihrer Tragfähigkeit. Wer einem Satz zuhört, kennt dessen Ende nicht und rechnet dennoch damit, dass weitere Wörter verständlich anschließen können.

Nicht alles Unerwartete unterbricht einen Zusammenhang. Eine überraschende Antwort kann aufgenommen werden und ein Gespräch in eine neue Richtung führen. Ein ungeplanter Einsatz kann eine musikalische Improvisation verändern, ohne sie anzuhalten. Unterbrechend wird eine Abweichung dort, wo sie sich nicht ohne Weiteres in die bisher verfügbaren Fortsetzungen aufnehmen lässt.

Unterbrechung und Fortsetzung sind deshalb keine einfachen Gegensätze. Eine Pause kann eine Tätigkeit gliedern und gerade dadurch ihre Wiederaufnahme ermöglichen. Ein Einwand kann eine Argumentation anhalten, damit sie ihre Voraussetzungen genauer bestimmen muss. Eine Trennung kann einen bisherigen Zusammenhang beenden und zugleich zur Bedingung anderer Anschlüsse werden. Auch das Unterbrechen bleibt innerhalb der Bewegung, in der Vollzüge weitere Vollzüge ermöglichen, begrenzen oder verändern.

## 3. Weisen des Unterbrechens

Unterbrechungen treten nicht in einer einheitlichen Gestalt auf. Für den weiteren Gang lassen sich vorläufig drei verschiedene Weisen unterscheiden, in denen Fortsetzbarkeit fraglich wird. Sie bilden keine erschöpfende Einteilung und liegen nicht auf derselben begrifflichen Ebene.

Ein **Ausfall** liegt vor, wenn ein erwarteter Anschluss nicht zustande kommt. Ein Gerät führt einen vorgesehenen Schritt nicht aus, eine Äußerung wird nicht verstanden oder eine eingeübte Handlung misslingt. Der Ausfall bezeichnet das Ergebnis, nicht seine Ursache. Eine Störung kann ihn verursachen, muss es aber nicht. Umgekehrt kann ein erwarteter Anschluss ausfallen, ohne dass sich ein einzelnes störendes Ereignis bestimmen lässt.

Eine **gesetzte Zäsur** ist ein Vollzug, durch den eine Fortsetzung bewusst angehalten oder gegliedert wird. Eine Pause, eine Frage, ein Einwand oder ein montierter Schnitt können eine solche Zäsur bilden. Das Aussetzen lässt häufig eine Wiederaufnahme offen. Es kann aber auch eine andere Richtung vorbereiten, ohne schon zu bestimmen, wie der Zusammenhang weitergehen wird.

Eine **Blockierung** bezeichnet Bedingungen, unter denen ein möglicher Anschluss nicht zugänglich oder nicht wirksam werden kann. Sie muss nicht als auffälliges Ereignis erscheinen. Gerade deshalb ist sie ein Grenzfall des Unterbrechungsbegriffs: Sie kann einer konkreten Fortsetzung vorausliegen, statt einen bereits laufenden Verlauf anzuhalten. Für Kapitel 2 ist zunächst nur festzuhalten, dass nicht jede verhinderte Fortsetzung als sichtbarer Ausfall erfahren wird.

Blockierung bleibt damit als Grenzfall des Unterbrechens festgehalten. Wie Blockierungen organisiert, verteilt und asymmetrisch wirksam werden, wird erst in den Kapiteln über Verteilen und Asymmetrie systematisch bestimmt.

## 4. Pause, Unterbrechung und Abbruch

Nicht jede Unterbrechung ist eine Pause. Eine Pause setzt einen Verlauf aus und hält seine Wiederaufnahme als Möglichkeit fest. Die Arbeit wird niedergelegt, das Gespräch angehalten, die Wiedergabe gestoppt. Was später wiederkehrt, muss deshalb nicht unverändert sein; die Pause bezeichnet nur, dass derselbe Zusammenhang als fortsetzbar behandelt wird.

Ein Abbruch beendet dagegen die mögliche Fortsetzung eines bestimmten Verlaufs. Insofern ist er eine Weise der Unterbrechung. Dass ein Verlauf endet, bedeutet jedoch nicht, dass mit ihm jede weitere Wirkung verschwindet. Ein abgebrochenes Gespräch kann eine spätere Auseinandersetzung, eine Trennung oder ein erneutes Gespräch unter anderen Bedingungen nach sich ziehen. Der bisherige Verlauf endet, aber sein Ende wird selbst zu einer Bedingung dessen, was folgen kann.

Fortsetzung bedeutet daher nicht notwendig Rückkehr. Nach einer Unterbrechung kann etwas wieder aufgenommen, verändert weitergeführt oder nicht mehr hergestellt werden. Neu entstehende Möglichkeiten ersetzen das Verlorene nicht automatisch. Unterbrechung ist deshalb weder von sich aus produktiv noch bloß negativ. Ihre Folgen lassen sich nicht aus dem Begriff allein ableiten.

## 5. Sichtbarkeit ohne Erkenntnis

Unterbrechungen können Bedingungen bemerkbar machen, die im Gelingen unauffällig mitwirkten. Ein unverständliches Wort lenkt die Aufmerksamkeit auf Sprache und Situation. Ein versagendes Werkzeug lässt nach den Voraussetzungen seiner Funktion fragen. Ein misslungener Übergang in einer Montage macht eine Erwartung an Rhythmus, Raum oder Bedeutung spürbar.

Doch Bemerkbarkeit ist noch keine Erkenntnis. Die Unterbrechung zeigt nicht ohne Weiteres, worin ihre Ursache liegt, welche Einheit unterbrochen wurde oder welche Fortsetzung angemessen wäre. Dieselbe Situation kann verschieden beschrieben werden: als individueller Fehler, als ungeeignete Regel, als widersprüchliche Erwartung oder als Folge eines umfassenderen Zusammenhangs. Keine dieser Deutungen ist durch das Ereignis allein festgelegt.

Unterbrechung macht daher nicht die Anschlussbedingungen vollständig sichtbar. Sie macht bemerkbar, dass die bisherige Fortsetzung von Bedingungen abhing, die nun nicht mehr unauffällig mitwirken. Erst eine weitere Untersuchung kann bestimmen, welche Unterschiede relevant sind und was als bearbeitbare Frage gefasst werden soll.

Damit ist die Grenze zu späteren Operationen bezeichnet. Unterbrechen ist noch keine Problematisierung, keine Bestimmung von Form und keine Kritik. Es kann zu ihnen Anlass geben. Es kann aber ebenso übergangen, ausgeglichen, verdrängt oder missverstanden werden.

## 6. Der Schnitt als Modell des Unterbrechens

In der Montage lässt sich die Beziehung zwischen Unterbrechung und Anschluss praktisch untersuchen. Der Schnitt ist nicht mit Unterbrechung identisch. Ein Kontinuitätsschnitt kann gerade darauf zielen, die gesetzte Grenze in der Wahrnehmung zurücktreten zu lassen. Umgekehrt gibt es Unterbrechungen ohne Schnitt. Als gesetzte Grenze und Neubestimmung einer Fortsetzung macht der Schnitt jedoch sichtbar, wie Unterbrechen die Bedingungen weiterer Anschlüsse verändern kann.

Bild- und Tonaufnahmen besitzen zeitliche Verläufe. Ein Schnitt setzt innerhalb dieser Verläufe eine Grenze, verkürzt Material oder trennt Ausschnitte voneinander. Zugleich bestimmt er eine Beziehung zwischen dem, was vor und nach dieser Grenze wahrgenommen wird. Ein Blick kann auf einen Gegenstand bezogen, eine Bewegung an einem anderen Ort fortgesetzt oder ein Geräusch mit einem noch unsichtbaren Bild verbunden werden. Der Schnitt erschafft diese Beziehungen nicht notwendig aus dem Nichts. Er aktualisiert, gewichtet oder verändert Beziehungen, die das Material und der bisherige Zusammenhang ermöglichen.

Der Schnitt garantiert dabei keinen tragfähigen Anschluss. Zwei Ausschnitte können technisch verbunden sein, ohne dass ihre Beziehung verständlich oder dem Material angemessen wird. Die Unterbrechung allein erzeugt noch keinen gelungenen Zusammenhang. Sie verändert die Bedingungen, unter denen ein solcher Zusammenhang entstehen kann.

Die früheren Montagearbeiten bereiten diese Einsicht vor, ohne bereits den heutigen Unterbrechungsbegriff zu verwenden. Die Bachelorarbeit beschreibt Rohmaterial, Haltung und jeweilige Filmfassung als aufeinander bezogene Momente des Montageprozesses; der entstandene Filmzustand wirkt auf die weitere Wahrnehmung und Entscheidung zurück.[^ba-unterbrechen] Die Masterarbeit fasst Montage als ein fortlaufendes Reagieren auf Material und entstehende Sequenzen. Das Vorgegebene verändert sich, indem neue Ordnungen und Bezugspunkte hervorgebracht werden.[^ma-unterbrechen]

Montage dient hier deshalb nicht als nachträgliches Beispiel. Im Setzen, Verschieben und Vergleichen von Schnitten wird erprobt, wie eine Trennung andere Beziehungen ermöglicht und wie jede Fassung die Bedingungen des weiteren Arbeitens verändert. Die Erkenntnis über Unterbrechung entsteht in diesem Arbeitsprozess und wird von dort für andere Zusammenhänge gewonnen.

Was am Schnitt verdichtet hervortritt, lässt sich vorsichtig auf andere Zusammenhänge beziehen: Eine Frage kann einen Redefluss anhalten und einen anderen Raum möglicher Antworten eröffnen. Ein Einwand kann eine Begründung unterbrechen und verändern, was anschließend ausgewiesen werden muss. Unterbrechen kann insofern selbst eine Weise des Anschließens sein. Es negiert den Zusammenhang nicht notwendig von außen, sondern aktualisiert eine Möglichkeit, durch die dessen Fortsetzbarkeit verändert wird.

## 7. Von der Unterbrechung zum Problem

Eine vollzogene Unterbrechung verändert den Raum weiterer Anschlussmöglichkeiten. Sie kann einen bisherigen Weg versperren, eine Wiederholung aussetzen oder eine andere Beziehung ermöglichen. Daraus folgt nicht, dass sie Offenheit, Erkenntnis oder Verbesserung hervorbringt. Manche Unterbrechungen lassen sich nicht produktiv wenden. Manche beenden Möglichkeiten, die nicht wiederhergestellt werden können.

Ebenso wenig folgt aus einer Unterbrechung automatisch ein Problem. Ein Ausfall kann behoben werden, ohne dass seine Bedingungen untersucht werden. Eine Zäsur kann ihren Zweck erfüllen und unauffällig in eine Fortsetzung übergehen. Eine Blockierung kann bestehen bleiben, ohne als solche wahrgenommen zu werden.

Problematisieren beginnt erst dort, wo die unbestimmte Fraglichkeit weiter bearbeitet wird. Dann muss unterschieden werden, was nicht weitergeht, welche Bedingungen dafür relevant erscheinen und woran eine Untersuchung oder Veränderung ansetzen kann. Aus dem Nichtweiterkönnen wird eine bestimmte Frage.

Das nächste Kapitel handelt vom Problematisieren.
