# Editor Pipeline

Diese Pipeline beschreibt den editorischen Arbeitsablauf.

## Reihenfolge
1. Automatenverbund
2. Unterscheidungsautomat
3. Redundanzautomat
4. Begriffsnetz
5. Tractatus-Automat
6. Kapitelautomat
7. Editor

## Entscheidungsregeln
- KEEP: notwendige argumentative Funktion
- SHORTEN: Wiederholung ohne neue Funktion
- MERGE: zusammenführen gleicher Begriffe oder Definitionen
- MOVE: an logisch passendere Stelle verschieben

## Prinzip
Erst prüfen, dann entscheiden, dann überarbeiten. Jede Revision muss argumentativ begründet werden.
