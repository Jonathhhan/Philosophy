# Philosophische Positionskarte

Status: Arbeitskarte für den Literatur- und Argumentationsapparat; kein Manuskriptkapitel.

Diese Karte ordnet das eigene Problemfeld möglichen philosophischen Gesprächsräumen zu. Sie dient nicht dazu, externe Autorinnen und Autoren als Begründungsersatz einzuführen. Jede spätere Aufnahme in das Manuskript benötigt eine konkrete Kapitelentscheidung, Quellenprüfung und, bei genauen Behauptungen, Seitenangaben.

## Leitfragen für die Literaturarbeit

1. Welches Problem löst die externe Quelle für das Kapitel?
2. Wird durch die Quelle eine eigene Differenz sichtbarer?
3. Droht die Quelle, eine fremde Theorieachse einzuführen?
4. Kann die Passage ohne Namensreferenz stärker argumentieren?
5. Ist die Quelle im Haupttext nötig oder reicht eine Fußnote?
