Zur Kritik der Organisation von Anschlussmöglichkeiten

Anschlusslabor · Aktualisieren und Stabilisieren

Ein operatives Begriffsmodell

Kein Anfang beginnt bei null.

Eine Äußerung schließt an Bedingungen an, die sie nicht selbst hervorgebracht hat. Sobald sie aktualisiert wird, verändert sie, was danach fortgesetzt, präzisiert, unterbrochen oder variiert werden kann. Erst das Festhalten einer Fassung gibt diesem Zusammenhang relative Dauer.

Die Interaktion bearbeitet einen Gedanken des Manuskripts. Sie ersetzt weder dessen Argumentation noch bildet sie einen ursprünglichen Manuskriptwortlaut ab.

Beobachtung

Noch wurde kein eigener Anschluss aktualisiert. Alphabet, Sprache, Interface und die Erwartung einer Fortsetzung wirken dennoch bereits als Bedingungen.

03

Relative Dauer

Eine Fassung stabilisieren

Festhalten bewahrt einen bestimmten Stand. Freigeben behandelt ihn vorläufig als maßgeblich. Beides schließt spätere Veränderung nicht aus und rechtfertigt die Fassung nicht.

Noch besteht keine stabilisierte Fassung.

Jede Aktualisierung verändert den Raum weiterer Anschlussmöglichkeiten.

Dass eine Anschlussordnung fortbesteht, begründet noch nicht, dass sie fortbestehen soll.
